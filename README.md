# 🏎️ FalseLap — Break the Cycle, Rule the Track

**FalseLap** is a fast-paced F1 racing game created by **Team Quidditch Players** during the **Formula Hacks Hackathon**.

Built from the ground up in just **22 hours**, the project focuses on delivering an engaging racing experience with an F1 car, a complete lap system, and smooth visuals.

> **BREAK THE CYCLE. RULE THE TRACK.** 🏁

---

## 🎮 About the Game

FalseLap puts you behind the wheel of an F1 car and challenges you to conquer the track.

The game features:

* 🏎️ **F1 Car Racing**
* 🏁 **Complete Lap System**
* 🎮 **Smooth and Responsive Gameplay**
* ✨ **Smooth Graphics**
* ⚡ **Rapid Hackathon Development**
* 🏆 Built during **Formula Hacks**

---

## ⏱️ Development

The entire project was conceptualized, developed, integrated, and polished within:

### **22 Hours**
